Subredes y hosts desde una máscara

  1. Clase → prefijo base (A /8 · B /16 · C /24).
  2. Máscara → contar unos: 255 = 8 · 0 = 0 · el byte del medio según la tabla.
  3. Bits de subred s = prefijo − base. Bits de host h = 32 − prefijo.
  4. Subredes válidas 2ˢ − 2. Hosts por subred 2ʰ − 2.

s se cuenta desde la base de la clase, no desde /24.

Clase A, 255.255.252.0 → 8+8+6 = /22 → s = 14, h = 10 → 16.382 subredes de 1022 hosts

Elegir la máscara

  • N subredes: menor s con 2ˢ − 2 ≥ N → prefijo = base + s.
  • H hosts: menor h con 2ʰ − 2 ≥ H → prefijo = 32 − h → s = prefijo − base.
  • Las dos: s y h por separado; controlar s + h ≤ 32 − base.
  • Prefijo → máscara: p ÷ 8 = bytes en 255; el resto va al byte siguiente (1→128, 2→192, 3→224, 4→240, 5→248, 6→252, 7→254); los demás en 0.

Es ≥, no >. "Máximo de hosts" → menor s. s = 1 da 0 subredes válidas.

204.12.30.0, 5 subredes → C /24, s = 3 → /27 = 255.255.255.224, 30 hosts
Clase B, 8 subredes de 2500 hosts → s = 4, h = 12 → /20 = 255.255.240.0

Direcciones

  1. Byte interesante: el de la máscara que no es 255 ni 0. Salto = 256 − byte.
  2. Subred N = N × salto en ese byte; a la derecha, 0. La N° 0 y la última no valen.
  3. Broadcast = inicio de la siguiente − 1 (a la derecha, 255).
  4. Hosts: red + 1 … broadcast − 1.
  5. IP dada → en ese byte, el múltiplo del salto ≤ al valor.
  6. Host H de la subred N = subred + H. Si H > 255: H = 256·q + r → q al byte interesante, r al último.

Hasta dónde llegan

  • Bloques = 2ˢ. Control: bloques × salto = 256 (si s entra en un byte).
  • Primera válida = 1 × salto. Última válida = 256 − 2 × salto.
  • Último bloque = 256 − salto = byte de la máscara (no vale).
  • Si N × salto ≥ 256, pasa al byte de la izquierda: 256·q + r.

160.20.0.0 / 255.255.248.0 → salto 8 en el 3er byte
subred 4 = 160.20.32.0 … 160.20.39.255 · última válida 160.20.240.0
host 1000 de la subred 6 = 160.20.48.0 + (3·256 + 232) = 160.20.51.232
