Elegí siempre el menor n o h que cumpla ≥ lo pedido. De /17 a /23, mismo patrón en el 3.er byte (/20 = 255.255.240.0).

A. Dividir en N subredes E4

  1. Menor n con 2ⁿ − 2 ≥ N → máscara = original + n.
  2. Salto = 256 − byte. Bloques: 0, salto, 2·salto…
  3. Descartar el 1.er bloque (bits 0…0) y el último (1…1).
  4. Listar: red · hosts · broadcast.

192.168.10.0/24, N = 6 → n = 3 → /27 (224) → salto 32 → .32 a .192

B. Subredes de H hosts E5

  1. Menor h con 2ʰ − 2 ≥ H → máscara = 32 − h.
  2. n = nueva − original → válidas = 2ⁿ − 2.
  3. Salto, descartar y listar como en A.

200.10.5.0/24, H = 50 → h = 6 → /26 (192) → n = 2 → válidas .64 y .128

C. IP + máscara → red y broadcast E1 · E2 · E3

  1. Byte interesante: el 1.º de la máscara que no es 255. Salto = 256 − ese byte.
  2. Red: múltiplo del salto ≤ IP en ese byte; a la derecha, 0.
  3. Broadcast: red + salto − 1; a la derecha, 255.
  4. ¿Misma subred? Calculá la red de cada IP: iguales → sí.

172.16.45.200 / 255.255.240.0 → salto 16 en el 3.er byte → red 172.16.32.0 · bc 172.16.47.255

D. Rango de hosts → máscara E6

  1. Red = 1.er host − 1 · broadcast = último host + 1.
  2. Bloque = broadcast − red + 1.
  3. Byte de la máscara = 256 − bloque (o tabla).
  4. Control: la red es múltiplo del bloque.

.65 a .94 → red .64 · bc .95 → bloque 32 → 255.255.255.224 (/27)

Trampas

  • Salto = 256 − byte, no 255.
  • Los bloques arrancan en 0 y en múltiplos del salto: .32 a .63.
  • Bloque (32) ≠ hosts (30). Contá con +1: 62 − 33 + 1 = 30.
  • Dos −2: hosts (red y bc, siempre) y subredes (1.ª y última, Baró).
  • La clase da la máscara por defecto; si el bloque es más chico, manda el bloque.
  • Escribí máscara, no "mac" (MAC = dirección física). Bloque, no "trama".
  • Revisá los 3 primeros bytes en toda la tabla.
  • Justificá: cuenta de 2ⁿ − 2, salto y qué bloques descartás.
