0 Antes de marcar: ¿qué pide?

"productos de trabajo bajo CM"solo PT que pasan los filtros. Nunca herramientas.
"viable de CM y no producto de trabajo"solo activos del caso (la plantilla vigente).
"si estuviera en el año X…"lo que existía en X y hace falta para reconstruir, herramientas incluidas.
"activos de proceso del proyecto"de cada plantilla, la más nueva antes del inicio, en formato vigente.

! Trampas

  • Herramienta ≠ PT: Word o Java son activos. Si la consigna no dice reconstruir / evolución / año X, no las marques (Word 2013, Java SE 7 → afuera).
  • Versión que el caso no nombra (Base-clase-v1.0) → distractor, afuera.
  • "Podrá deducir que debió estar" → código fuente (si hay una app) y documentación de los requerimientos. Casi nunca se nombran y casi siempre van.
  • Preguntas espejo: buscá el "no" en la consigna.
  • "PT a nivel organizacional" → NINGUNA. Si dice activos → OPD.
