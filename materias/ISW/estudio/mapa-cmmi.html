VER vs VAL: ¿contra qué se compara el artefacto?

Contra OTRO DOCUMENTO del proyecto → VER
(reqs, especificación, diseño, particiones, estándar técnico) · "¿lo construí bien?" · lo juzga el EQUIPO
Contra la NECESIDAD REAL del cliente → VAL
(no hay documento "más arriba": el único que sabe si está bien es él) · "¿construí lo correcto?" · lo juzga el CLIENTE

¿Qué artefacto va con cuál?

VAL (lo entiende y juzga el cliente): lista inicial de reqs F/NF · minuta revisada CON el cliente · prototipo (demostrarlo = validar) · manual de usuario · software en el entorno real · aceptación, piloto, beta
VER (técnico, contra otro documento): diagramas · modelo y diccionario de datos · casos de prueba, particiones · código fuente · plan de proyecto · BD de prueba (entorno de verificación) · minuta revisada ENTRE NOSOTROS · pruebas unitarias, integración, sistema
NINGUNA: BD de producción, herramientas, el repositorio
